# Open the Manager

`OpenLAPP: Open Manager` opens a full-page editor for the system LAPP profile. The first time, you must accept that this is a shared per-user location, not a private store for this extension alone.

The page stays in the editor area. It never creates an Activity Bar container or a custom chat participant. Use it to inspect platform status, Vault metadata, eligible Copilot models, and diagnostics.
